# Amar App

এটি Capacitor দিয়ে তৈরি একটি সিম্পল অ্যান্ড্রয়েড অ্যাপ।

## কিভাবে APK বানাবে (GitHub Actions)

1. এই রিপোজিটরিতে **Actions** ট্যাবে যাও
2. বাম পাশে **Build Android APK** সিলেক্ট করো
3. **Run workflow** বাটনে ক্লিক করো
4. ৫-১২ মিনিট অপেক্ষা করো
5. বিল্ড শেষ হলে **Artifacts** থেকে `app-debug` ডাউনলোড করো
6. ZIP খুলে `.apk` ফাইল পাবে → ফোনে ইন্সটল করো
